# Basic Inventory System
This project supply the necessity of manage the students data, this system created in Python allows users to manage students data using CRUD operations (Create, Read, Update, Delete) and supports saving and loading the data from a CSV file.

## 🚀 Features
- **Students management**: Register and manage students.
- **Register new students**: Add new students with details like id,name, age, course and state.
- **Consult list of students**: Display the list of all registered students.
- **Search student**: Display the data of a single student.
- **Update data of a student**: Update the student data like name, age, course and state.
- **Delete student**: Remove students from the students list.
- **Save CSV**: Export the students list data to a CSV file.
- **Load CSV**: Import the students list data from a CSV file.

## 📦 Installation (Local)
### 1. Clone this repository
```bash 
git clone https://github.com/Danilo-Doria/Sistema-de-Gestion-de-Estudiantes-con-Persistencia-de-Datos.git
cd Sistema-de-Gestion-de-Estudiantes-con-Persistencia-de-Datos
```

### 2. Run the program
```bash
python app.py
```

## ▶️ Usage
After running the program, a menu will appear in the terminal where you can:
1. Register new students
2. Consult list of students
3. Search student
4. Update data of a student
5. Delete student
6. Save in CSV file
7. Load from CSV file
8. Exit
